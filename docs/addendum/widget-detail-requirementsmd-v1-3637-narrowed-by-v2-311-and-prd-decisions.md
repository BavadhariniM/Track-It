# Widget Detail (requirements.md v1 §36–37, narrowed by v2 §31.1 and PRD decisions)

- v1 originally proposed size-based widgets (Small/Medium/Large) with open-ended content per size. v2 narrowed this to exactly three purpose-based types (Today/Week/Month); the PRD decision session further scoped widgets to home-screen only (no lock-screen), which also removes v1's iOS lock-screen widget consideration from MVP.
- Quick actions (e.g. marking a Boolean goal complete directly from a widget) were named as "potential" in v1 §37 but not confirmed during PRD creation — not carried into the PRD as an FR. Worth revisiting in the UX phase if widget interaction depth becomes a priority.
