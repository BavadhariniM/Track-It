# 1. Vision

Tracker is an offline, privacy-first habit and goal tracker for a single user — its builder, for now and by design — that treats commitments as more than a daily checkbox. Goals carry real rules: an evaluation period, an eligible-days schedule, a tracking type, and a target comparison. A rule engine evaluates every goal against those rules and against logged history, so the calendar's status for any day, week, or month is always *earned* — computed from what actually happened — never guessed or hand-set.

Where generic habit trackers flatten "did I do the thing today" into a binary and quietly lose the user's trust the moment the math doesn't match reality, Tracker's edge is getting the evaluation logic right — including the exotic scheduling patterns (every-N-days recurrence, Nth-weekday-of-month, rolling windows) that real commitments actually have and that most trackers don't bother to model correctly. Honestly stated, that edge is an execution advantage, not a defensible one — there's nothing technically novel here, and it should be treated as such. That correctness *is* the product anyway, because it's the thing that determines whether its single user actually trusts and keeps using it.
