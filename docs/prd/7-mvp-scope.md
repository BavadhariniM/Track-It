# 7. MVP Scope

## 7.1 In Scope

- Full Goal engine including exotic recurrence (every-N-days/weeks/months, Nth-weekday-of-month, custom dates, biweekly, quarterly, Rolling Windows, Blackout Dates) and free combination of all scheduling/target axes.
- Guided goal-creation flow.
- Boolean and Counter tracking (with decimal support and repeated same-day increments), Cheat Days (per-period quota), Goal Versioning with a visible Version Timeline, Archive-as-delete.
- Day/Week/Month calendar views, configurable week-start, goal/category filtering, a distinct Pending status for future/in-progress dates.
- Midnight rollover handling.
- Dashboard, Goal detail screen, statistics, rule-aware Streaks.
- Local notifications (single global time).
- Three home-screen widgets (Today/Week/Month), cached-status-only.
- JSON export and merge-import with conflict prompts and validation.
- Reset/erase-all escape hatch, with confirmation.

## 7.2 Out of Scope for MVP

See §6 Non-Goals — this list is identical; MVP scope and product scope are the same boundary for this project (no planned v2 in this PRD's horizon).
